当 `VirtualService` 引用了 Istio 根据 Kubernetes Gateway API `Gateway`
生成的内部 `Gateway` 时，会出现此消息。

这些内部网关的名称中包含 `~istio-autogenerated-k8s-gateway~`。它们是 Istio 的实现细节，
其名称可能会发生变化，您不应引用它们。

## 示例 {#example}

假设有如下 `VirtualService`：

{{< text yaml >}}
apiVersion: networking.istio.io/v1
kind: VirtualService
metadata:
  name: httpbin
spec:
  hosts:
  - httpbin.example.com
  gateways:
  - istio-system/gateway-istio-autogenerated-k8s-gateway-default
  http:
  - route:
    - destination:
        host: httpbin
{{< /text >}}

您将收到如下消息：

{{< text plain >}}
Warning [IST0165] (VirtualService default/httpbin) Gateway reference in VirtualService default/httpbin is to an implementation-generated internal Gateway: istio-system/gateway-istio-autogenerated-k8s-gateway-default.
{{< /text >}}

## 如何修复 {#how-to-resolve}

执行以下操作之一：

- 使用引用 Kubernetes Gateway API `Gateway` 的 `HTTPRoute`。
- 创建一个 Istio `Gateway` 资源，并在 `VirtualService` 中引用它。
